# Fontes de assinatura de terceiros

Estas fontes vieram do projeto guild-briefings e são de **uso pessoal** (algumas são versão demo). Elas **não fazem parte da licença MIT** do OPORD, e cada uma segue os termos do autor dela.

| Arquivo | Fonte |
| --- | --- |
| `attallia.otf` | Attallia Signature (Personal Use Only) |
| `autograf.ttf` | Autograf (Personal Use Only) |
| `bastliga-one.otf` | Bastliga One |
| `honofly.otf` | Honofly |
| `montreuil.ttf` | Montreuil Signature |
| `patricia-wilcie.otf` | Patricia Wilcie (Demo) |
| `the-scientist.ttf` | The Scientist |

As fontes livres (OFL e Apache) vêm pelo `@fontsource`, listadas em `package.json`.
